# Turtle Pookalam (Onam Floral Carpet)

A vibrant, digital Pookalam (traditional floral carpet from Kerala, India) created using Python's `turtle` graphics library.

## 🌟 Features

* **Layered Geometry:** Generates patterns using precise mathematical formulas 
* **Traditional Color Palette:** Uses rich festive colors like maroon, orange, yellow, and green.
* **Dynamic Scaling:** Structures shapes in descending sizes to create a traditional layered rug appearance.
* **Festive Greeting:** Displays a stylized "Happy Onam!" message upon completion.

---

### Prerequisites

Make sure you have Python installed on your system. The `turtle` and `math` modules are part of the Python Standard Library, so no additional installations are required.

## Installation & Running

1. Clone the repository:

```bash
git clone https://github.com/Pavi-thra-Mohan/Pookalam-using-Python-Turtle.git
```

2. Navigate to the project directory:

```bash
cd Pookalam-using-Python-Turtle
```

3. Run the script:

```bash
python TurtlePookalam.py
```


   
## 📐 How it Works

The design is constructed sequentially from the outermost layer to the center:

* **Background & Base:** A solid white background with a large dark maroon base circle.
* **Triangular Outer Ring:** An intricate 36-spoke interlocking triangular pattern scaled down across 4 distinct color changes.
* **Hexagonal Mid-Ring:** Concentric hexagons drawn with alternating green and white borders.
* **Square Inner Core:** Rotating squares creating a star-like center pattern.
* **Centerpiece:** A traditional two-tone diamond petal design capped with a maroon center dot.
